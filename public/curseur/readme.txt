Plants Vs Zombie Set
====================

Author:
  - Unknown

This animated cursor set contains 5 cursors.

Installed by install.inf (5 files):
  - Spinning Peashooter Projectile - Plants Vs Zombie_32-48-64.ani (multisize: 32, 48, 64px)
  - Sun - Plants Vs Zombie_32-48-64.ani (multisize: 32, 48, 64px)
  - Pointer - Plants Vs Zombie.cur
  - Gloves - Plants Vs Zombie.cur
  - Spinning Peashooter - Plants Vs Zombie_32-48-64.ani (multisize: 32, 48, 64px)

Extras (6 files) — not installed automatically:
These are alternates and spare cursors included with the set. To use one,
copy it over the installed file it replaces, then re-apply the scheme in
Control Panel > Mouse > Pointers.
  - Spinning Peashooter Projectile - Plants Vs Zombie_72-96-128.ani (multisize: 72, 96, 128px)
  - Spinning Peashooter Projectile - Plants Vs Zombie_256.ani (256px)
  - Sun - Plants Vs Zombie_72-96-128.ani (multisize: 72, 96, 128px)
  - Sun - Plants Vs Zombie_190.ani (190px)
  - Spinning Peashooter - Plants Vs Zombie_72-96-128.ani (multisize: 72, 96, 128px)
  - Spinning Peashooter - Plants Vs Zombie_256.ani (256px)

Installation:
  1. Right-click install.inf
  2. Select 'Install'
  3. Open Control Panel > Mouse > Pointers
  4. Select 'Plants Vs Zombie Set' from the Scheme dropdown
